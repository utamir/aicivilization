# WHAT IF? Civilization Lab v11.4 — Release candidate

Complete source, autonomous reconstruction prompt, evidence/red-team material, prebuilt browser runtime, and no-Node launchers.

**Public demo:** https://aicivilization.fyi

Start with `README.md`. Developers should use `README-DEV.md`. Autonomous rebuilds should start from `MASTER_PROMPT.md`. There are intentionally only two README files in the repository root.

Runtime: Python 3 + a modern browser. Node/npm are not required for the included prebuilt build. The browser runtime currently loads version-pinned React/Three dependencies from esm.sh, so internet access is required.
